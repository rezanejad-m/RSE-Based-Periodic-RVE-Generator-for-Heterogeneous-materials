# RSE-Based Periodic RVE Generator for Heterogeneous Materials

## Overview

This repository presents a MATLAB-based implementation of the Random Sequential Expansion (RSE) algorithm for generating statistically random periodic Representative Volume Elements (RVEs) of heterogeneous materials.

The developed framework enables the generation of microstructures with prescribed inclusion volume fractions while ensuring non-overlapping particle placement and periodicity of the representative domain.

## Key Features

- Random Sequential Expansion (RSE) algorithm
- Periodic Representative Volume Elements (RVEs)
- Controlled inclusion volume fractions
- Non-overlapping particle placement
- Batch microstructure generation
- MATLAB implementation

## Applications

- Heterogeneous and composite materials
- Computational homogenization
- Microstructure modeling
- Finite Element Analysis (FEA)
- Materials science research

## Notes

The repository is intended to demonstrate the methodology and capabilities of the developed framework. Core source codes are not publicly released.
